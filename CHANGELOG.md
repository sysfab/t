# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-04

### Added

- Iteration helpers for array and map-like tables.
- Predicates and checks for emptiness, value and key membership, shape, and
  equality.
- Transformation helpers for filtering, mapping, reducing, grouping, indexing,
  partitioning, key mapping, projection, flattening, slicing, chunking, and
  zipping.
- Set operations for unique values, unions, intersections, and differences.
- Shallow and deep copying and merging with cycle support.
- Array choice, shuffling, and reversal helpers.
- In-place variants under the `nocopy` namespace.
- Direct access to supported native `table` functions.
